# Farming Simulator 25 Export

This export is a Farming Simulator 25 map mod generated by MapToPlay.

## Open It

1. Download GIANTS Editor for FS25 from the GIANTS Developer Network:
   https://gdn.giants-software.com/downloads.php
2. Unzip this export.
3. Open `map/map.i3d` in GIANTS Editor.
4. Review the terrain, roads, fields, buildings, trees, and water.
5. Add your own details, adjust placements, tune fields, decorate the map, and save it in GIANTS Editor.

## Play It

Copy the exported mod folder or a correctly packed zip into:

`%USERPROFILE%\Documents\My Games\FarmingSimulator2025\mods`

Start Farming Simulator 25, enable the mod, and create a new save with the map.

## Zip It Correctly

If you zip the mod, open the exported mod folder and zip the contents inside it.

Do not zip the parent folder itself. The zip root must contain files like `modDesc.xml` and `map/`, not another folder around them.
